# SIMAS Masjid

Sistem Informasi Keuangan Masjid berbasis:

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Cloudflare Pages


## Fitur

- Login pengguna
- Role admin/bendahara/jamaah
- Pemasukan
- Pengeluaran
- Upload bukti transaksi
- Laporan keuangan
- Grafik
- Transparansi publik


# Instalasi Lokal


Clone project:


git clone https://github.com/username/simas-masjid.git


Masuk folder:


cd simas-masjid-cloudflare


Install:


npm install



Buat file:


.env.local



Isi:


NEXT_PUBLIC_SUPABASE_URL=

NEXT_PUBLIC_SUPABASE_ANON_KEY=



Jalankan:


npm run dev



Buka:


http://localhost:3000



# Deploy Cloudflare


Build command:


npm run build



Framework:


Next.js



Environment:


Node 20
